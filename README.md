# FieldSight 🛰️
A minimum viable product autonomous crop disease detection rover.

## Project Structure
- **/frontend**: React + CSS + Mapbox
- **/backend**: FastAPI + MySQL + Gemini AI + OCI
- **/microcontroller**: Raspberry Pi Hardware Control (motor, GPS, camera)
